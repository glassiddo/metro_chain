# Paris Métro Chain

Play at **[metrochain.netlify.app](https://metrochain.netlify.app/)**.

## Rules

1. Choose any Paris Métro station to start.
2. Jump along the same line to any later interchange or terminus shown in the choices.
3. Every intermediate station is automatically added to your chain and score.
4. You cannot take a route that crosses a station already used.
5. Keep going until no valid jump remains. Your score is the number of stations collected.

The game covers Métro lines 1–14, 3bis, and 7bis. It is untimed and has no undo.

Transit data: Île-de-France Mobilités and ITO World. This independent project is not affiliated with or endorsed by RATP or Île-de-France Mobilités.
